# G7.1：UI 职责拆分与功能组件化重构

> 实施日期：2026-07-25
>
> 基线：G7 代码与本地自动化完成，G8 规模和组合签字尚未执行
> 目标：在不改变产品行为的前提下，把顶层 Document/View 收敛为兼容组合外壳

## 1. 重构边界

G7.1 不修改 SECVID03、业务服务、用户数据 JSON、Document Scope 或既有交互语义。顶层
`View`/`ViewModel` 的名称、命名空间和构造函数保持不变，宿主 `ViewLocator` 与四个
`DocumentStrategy` 无需迁移。

新增的 UI 功能包为：

| 功能包 | ViewModel 边界 | View 边界 |
| --- | --- | --- |
| `Playback` | 播放协调、状态、控制、选项、媒体和呈现入口 | 部署、唯一视频表面、日常控制、轨道选项、全屏呈现和快捷键 |
| `Library` | 目录/投影协调以及播放、历史、布局入口 | 设置、虚拟化列表、显式激活和播放页脚 |
| `Encryption` | 批次状态唯一所有者和队列入口 | 队列、密码/冲突选项和执行汇总 |
| `Decryption` | 批次状态唯一所有者和队列入口 | 候选队列、输出/密码选项和执行汇总 |
| `SingleVideo` | 文件/密码与公开信息两个独立状态所有者 | 文件选择和公开信息编辑 |

顶层兼容类型继承或组合功能包实现，因此既有属性和命令仍指向同一状态，没有复制第二份
进度、密码、队列或媒体库投影。

## 2. View 设计

顶层 AXAML 只排列子 View。文件和目录选择器移动到实际发起操作的子 View，并保留防重入、
发起者捕获和 `DataContext` 复核。媒体库双击/Enter 激活归入列表 View；顶层媒体库 View
只保留首次初始化和基于像素宽度切换 `SplitView` 模式。

播放器始终只有一个 `PlaybackViewportView/EmbeddedVideoSurface`。`FullscreenPlaybackPresenter`
在普通占位区和宿主覆盖层间迁移同一 `PlayerShell`，等待旧 HWND 销毁后才连接新表面。
`PlaybackShortcutRouter` 只在播放器作用域映射命令，并避开文本框、下拉框、滑块、列表和按钮。

## 3. 状态与生命周期

- 单文件密码由 `SingleVideoSourceViewModel` 唯一拥有，释放时显式清空。
- 公开信息由 `PublicInfoEditorViewModel` 唯一拥有；编辑前先通过播放媒体组件清理文件句柄。
- 加密、解密的实现分别位于功能包 `EncryptionBatchViewModel`、
  `DecryptionBatchViewModel`；顶层 Document 是无状态兼容子类。
- 播放和媒体库的大型协调实现移入对应功能包；顶层类型只承担宿主兼容名称。
- 所有原有代次、取消、事件退订和不重复释放注入服务的规则保持不变。

## 4. 兼容与验证

`G71UiCompositionTests` 固定以下事实：

- 五个顶层类型仍存在，但实现基类属于对应功能包；
- Browser、Library 功能切片引用同一个兼容实例，不复制状态；
- 单文件顶层属性继续代理子 ViewModel，关闭后密码为空。
