## 6. S1 需要优先保护的不变量

1. 单例 Tool 不持有 scoped Document/播放器；独立打开设置不加载 LibVLC。
2. 新默认值只影响新文档；记录策略和清理影响所有已有文档。
3. 保存成功对应真实提交；旧异步结果不能覆盖新草稿或新磁盘状态。
4. 清理/禁用后的旧记录不能被 Upsert、定时回调、关闭 Flush 或备份恢复复活。
5. 自动选择 Common 优先；指定路径无效时不静默换源；真实加载尝试后不热切换。
6. Common 只读复用；不混搭模块、不删除公共目录、不依赖音乐插件对象。
7. 精简输出保留托管桥接，缺库仍能打开设置及加解密功能。
8. 开发检查不启动发布、部署或 Windows CI 流程。
